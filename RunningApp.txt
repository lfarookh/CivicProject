What it does

Login and sign-up: Users create an account as a person, organization, government institute or government agency. Sign-in is by email and password, using JWT tokens.
Home page and network feed: Users post updates, like posts, and filter the feed by account type. The feed loads more posts as you scroll and refreshes when you pull down.
Verified badge: New accounts start unverified. Someone must set verified = 1 in the users table after checking an organization’s or agency’s credentials. There is no admin screen for this yet.
Folders in the zip

backend/ is Spring Boot 3 on Java 17, with MariaDB and a docker-compose.yml for local use.
mobile/ is an Expo (React Native) app that runs on Android, iOS and the web from one codebase.
infra/deploy-aws.sh and the README.md cover deployment to AWS. The README lays out the AWS setup and what to harden before going live. The script has not been run either.
To run locally

In backend/, run docker compose up --build. The API comes up on port 8080.
In mobile/, run npm install, then npm run web, npm run android or npm run ios.
For the Android emulator, set EXPO_PUBLIC_API_URL=http://10.0.2.2:8080.
AWS setup

Database: Amazon RDS for MariaDB in private subnets, with the database password and JWT secret kept in Secrets Manager.
API: The backend Docker image goes to ECR and runs on App Runner or ECS Fargate.
Web app: The built web files go to S3 and are served through CloudFront.
Phone apps: Android and iOS builds go through Expo’s EAS Build.
